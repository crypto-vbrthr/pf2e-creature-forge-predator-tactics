# Predator Tactics 0.1.0-dev.5 – Rules Text Clarity Review

This pass addresses abilities whose prose did not fully define when or how they were used.

## Key clarification

**Rake the Fallen / Am Boden zerfetzen** is a one-action ability used on the predator's own turn against **any prone creature within melee reach**. It is **not** a reaction to a creature falling prone or Standing. On a hit, it adds 2 damage per damage die of the Strike.

## Other clarified abilities

Relentless Pursuit, Cornered Fury, Latching Bite, Cull the Weak, Sudden Burst, Stalker's Patience, Shadow the Quarry, Crushing Grip, Finish the Hunt, Savage Reversal, and Apex Instinct now state concrete triggers, requirements, effects, durations, or movement limits instead of relying on narrative shorthand.

No provider API or Creature Forge schema changes are required.
