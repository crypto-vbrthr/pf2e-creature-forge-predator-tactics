# Predator Tactics 0.1.0 — Stable Release Review

## Release decision

Predator Tactics 0.1.0 is the stable promotion of the Foundry-smoke-tested 0.1.0-rc.1 build. No ability mechanics, selection rules, localization strings, or provider behavior were changed for the promotion.

## Included content

- 25 predator-themed Creature Forge abilities.
- Ambush & Hunt, Positioning & Pack Tactics, Pursuit & Mobility, and Finishers & Brutality review passes completed.
- Interactive PF2e action/check/save controls through Creature Forge Interactive Ability Actions.
- Send Ability to Chat support.
- Soft density balancing so the add-on enriches rather than overwhelms the Creature Forge core pool.
- Family exclusions for overlapping pursuit, finisher, initiative, and pounce packages.
- German and English localization.

## Compatibility

- Foundry VTT 14+.
- PF2e 8.4.0+.
- PF2E Creature Forge 1.1.0-dev.1+ (tested dependency floor for interactive ability support).

## Validation

The stable archive is built from the already Foundry-tested release candidate. The packaged release is re-tested with the add-on test suite and syntax checks before distribution.
